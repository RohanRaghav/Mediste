Mediste

A React-based web application built to deliver a smooth and responsive user experience.
This project uses React Router, Axios, TailwindCSS, and React Slick to provide navigation, data fetching, styling, and interactive carousels.

🚀 Tech Stack

Frontend: React 18, React Router DOM

Styling: TailwindCSS, Slick Carousel, React Slick

Data Handling: Axios

Build Tools: React Scripts

Deployment: Vercel

📦 Installation

Clone the repo and install dependencies:

git clone https://github.com/yourusername/mediste.git
cd mediste
npm install

⚡ Available Scripts

In the project directory, you can run:

npm start

Runs the app in development mode at http://localhost:3000
.

npm run build

Builds the app for production in the build folder.

npm test

Launches the test runner in interactive watch mode.

npm run eject

⚠️ Ejects configuration files (Webpack, Babel, ESLint). This is irreversible.

🎨 Features

📱 Responsive UI powered by TailwindCSS

🔄 Data Fetching with Axios

🛣️ Navigation handled by React Router DOM

🎠 Carousel & Sliders with React Slick and Slick Carousel

☁️ Easy deployment via Vercel
